猜猜我是谁｜TF FAMILY 双人联机版

【快速试玩】
1. 电脑需安装 Node.js 18 或更新版本：https://nodejs.org/
2. 解压整个压缩包。
3. Windows：双击 start.bat
   macOS：右键 start.command 选择打开，或在终端运行 ./start.command
4. 浏览器打开 http://localhost:3000
5. 玩家1点击“创建房间”，把邀请码发给玩家2。
6. 玩家2在另一台电脑/浏览器打开同一个服务地址，输入邀请码加入。
7. 两人到齐后，房主点击“开始游戏”。

【同一台电脑试玩】
打开两个浏览器标签页（或一个普通窗口、一个无痕窗口），第一个创建房间，第二个加入邀请码即可。

【跨设备说明】
此压缩包内置轻量服务器，房间数据只保存在运行服务器的电脑内存中。两位玩家要真正跨设备联机，需要把程序部署到一台可被两人访问的服务器；在同一 Wi-Fi 下，也可以使用运行服务器电脑的局域网 IP 地址和端口 3000。仅把 HTML 文件发给好友不能实现实时联机。

【玩法】
- 每局从角色库随机抽取25人，完全不按代际筛选。
- 两位玩家看到相同的25张人物卡，双方的秘密C位都从这25人中抽取。
- 当前玩家提问，对方只可回答“是 / 不是 / 不确定”，然后交换提问权。
- 在自己的回合可以输入姓名猜对方C位。猜对立即显示胜负弹窗；猜错轮到对方。
- 点击人物卡可在自己的面板上做排除记号；不会影响对手。
- 游戏结束后可重新随机25人开始新一局。

【注意】
- 房间是临时的；关闭服务器后房间数据会消失。
- 这是可运行的原型版，不含账号系统、持久化数据库或公开互联网托管。
- 人物照片取自用户提供的《一代｜TFBOYS.docx》文件。


【房间加入说明】创建者和加入者必须分别打开游戏（两个设备，或同一台电脑的两个独立浏览器标签页）。创建者创建后，把 6 位邀请码发给好友；好友在大厅的“房间邀请码”框中输入后点击“加入好友房间”。如需自己重新加入大厅，点击房间页的“返回大厅”。
