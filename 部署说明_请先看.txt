猜猜我是谁｜时代峰峻版 · 双人实时联机部署包

我已经检查过这份程序：Node.js 本地启动成功；创建房间、加入房间、随机25人、开始游戏、提问与回答接口均通过基础测试。

重要：这份压缩包是“可部署的程序”，还不是已经公开上线的网址。真正两台 iPhone 跨网络联机，需要把它发布到支持 Node.js 的云端服务。仅把 ZIP 或 HTML 发给朋友不够。

程序入口：server.js
启动命令：npm start
运行环境：Node.js 18 或更新版本
监听端口：使用平台提供的 PORT，绑定 0.0.0.0
网页和角色图片：public/ 文件夹

部署平台须知：
- 需要在支持 Node.js 后台服务的平台发布；不能选择 Static Site/纯静态托管。
- render.yaml 已附上，方便支持 Blueprint 的托管平台识别服务配置。
- .replit 也已附上，供 Replit 项目识别启动命令。
- 云平台可能要求登录、导入代码并点击 Deploy/Publish；我不能在没有你授权登录会话的情况下替你注册账号、接受条款或点击付费。

发布成功后的使用方法：
1. 在云平台打开它提供的公开 HTTPS 网址。
2. 玩家甲输入昵称，点“创建新房间”。
3. 把 6 位邀请码发给玩家乙。
4. 玩家乙打开同一个 HTTPS 网址，输入邀请码并点“加入好友房间”。
5. 两人加入后由房主点击“开始游戏”。

玩法：每局随机25位角色，不按代际筛选；双方各自有秘密 C 位；提问只允许“是 / 不是 / 不确定”；可在自己面板排除角色；猜中显示胜利弹窗。

注意：房间暂存在服务器内存里。服务休眠、重启或重新部署后，当前房间可能消失；本原型尚无账号或持久化数据库。

安全：不要把云平台密码、验证码、Cookie 或 API 密钥发到聊天中。
